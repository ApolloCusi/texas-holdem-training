# Cómo tirar paro

¡Gracias por querer poner de tu parte!

1. Haz un fork y clónalo.
2. Instala dependencias: `pip install -r requirements.txt`
3. Crea una rama: `git checkout -b mi-mejora`
4. Haz tus cambios y agrega tests en `tests/`.
5. Verifica que todo pase: `python -m pytest -v`
6. Abre un Pull Request explicando qué cambiaste y por qué.
